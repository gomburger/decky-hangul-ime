# Hangul IME Bridge

Steam Deck 게임 모드에서 Proton(Wine) 게임에 한글을 입력하게 해 주는 Decky Loader 플러그인입니다. Steam 가상 키보드와 물리 키보드를 모두 지원합니다.

## 필요한 것

- 게임 모드로 실행 중인 Steam Deck
- [Decky Loader](https://decky.xyz/)
- Proton으로 실행하는 게임 (Steam 게임, 비 Steam 게임 모두 가능)

## 설치

1. [릴리스 페이지](https://github.com/gomburger/decky-hangul-ime/releases/latest)에서 `decky-hangul-ime-<version>.zip`을 Steam Deck에 내려받습니다.
2. Decky 설정에서 개발자 모드를 켭니다.
3. Decky 설정의 **개발자** 메뉴에서 **ZIP으로 플러그인 설치**를 선택하고 내려받은 파일을 고릅니다.

업데이트도 같은 방법으로 설치하면 됩니다. 설정은 유지됩니다.

## 빠른 시작

1. 게임을 실행하고 Quick Access 메뉴(`…` 버튼)에서 **Decky → 한글 IME**를 엽니다.
2. **이 게임에서 사용**을 켭니다. 게임 실행 옵션에 `XMODIFIERS=@im=hangulbridge`가 자동으로 추가됩니다.
3. **게임을 완전히 끄고 다시 실행합니다.**
4. 입력창에서 한/영을 바꾸고 한글을 입력합니다.

한글이 `?`나 □로 보이면 **고급 → 실행 옵션**에서 **한국어 환경으로 실행**을 켜고 게임을 다시 실행하세요.

## 한/영 전환과 Steam 가상 키보드

- **물리 키보드**: 한/영 키, 오른쪽 Alt, Shift+Space. 쓸 키는 **고급 → 한/영 전환 키**에서 고릅니다.
- **가/A 버튼**: 플러그인 화면의 버튼으로 전환합니다.
- **Steam 가상 키보드**: 지구본 키가 한/영 전환 키가 됩니다. 키보드 설정에 한국어와 영어 자판을 함께 추가해 두세요.

Steam 가상 키보드의 한국어 자판으로 친 글자는 플러그인이 두벌식으로 조합합니다. 한글 상태에서는 Caps Lock과 길게 누르기(확장 문자)가 동작하지 않습니다. Steam 자체 입력창(오버레이 채팅, 브라우저 등)에서는 원래대로 동작합니다.

## 게임별 옵션

**이 게임에서 사용**을 켠 게임에서만 보입니다. 각 옵션의 기본값과 자세한 설명은 패널에 함께 표시됩니다.

**키보드 닫으면 영문으로** (기본 켜짐): Steam 가상 키보드를 닫으면 영문으로 바꾸고, 다시 열면 이전 한/영 상태로 돌아갑니다. 키보드로 조작하는 게임에서 채팅 후 한글 상태가 남으면 WASD 같은 조작키가 한글로 입력되어 캐릭터를 움직일 수 없게 되는데, 이를 막아 줍니다.

**글자 보내는 방식**: 드롭다운 메뉴에서 고릅니다. 먼저 기본 방식으로 써 보고, 맞지 않을 때만 바꾸세요.

| 방식 | 언제 쓰나요 |
|---|---|
| **기본 (IME)** | 대부분의 게임. 조합 중인 글자를 게임 입력창에 보여 줍니다. |
| **조합 중 글자 바로 입력** | 조합 중인 글자가 안 보이고 조합 창이 따로 뜨는 게임 |
| **붙여넣기로 입력** | IME로 한글이 안 되지만 Ctrl+V는 되는 게임 |

붙여넣기에서는 **모아서 입력**(기본 켜짐)으로 입력한 한글을 입력줄에 모았다가 Enter로 한 번에 보냅니다. Esc를 누르면 버리고, 영문 전환이나 다른 키를 누르면 Enter 없이 보냅니다.

**Enter 후 IME 깨우기** (기본 꺼짐): 채팅을 보낸 뒤 입력창을 다시 열면 한글이 안 들어가는 게임에서 켭니다. 그래도 안 되면 **Enter 후 입력 대기**를 늘리세요.

## 공통 설정

- **엔터 눌러도 키보드 유지**: Enter를 눌러도 Steam 가상 키보드를 닫지 않습니다.
- **키보드 불투명도**: Steam 가상 키보드를 반투명하게 합니다.
  - **데스크톱 모드에서 끄기**: 데스크톱 모드에서는 키보드 불투명도를 적용하지 않습니다. 불투명도를 100% 미만으로 낮추면 나타납니다.
- **고급**: 입력 서버 상태, 한/영 전환 키, 한국어 실행 옵션, 실행 중인 게임 프로세스를 확인하고 바꿉니다. **Steam 가상 키보드** 표시등이 계속 노랑이면 Steam 업데이트로 예비(fallback) 방식으로 동작하고 있을 수 있습니다.
- **등록된 게임**: 플러그인을 켠 게임을 확인하고 제거합니다. 제거하면 실행 옵션의 `XMODIFIERS`도 지웁니다. 게임 목록은 Steam 계정마다 따로 저장됩니다.

## 문제 해결

| 증상 | 해 볼 것 |
|---|---|
| 토글을 켰는데 한글이 안 됨 | 게임을 완전히 끄고 다시 실행합니다. |
| "실행 옵션이 적용되지 않았어요"가 보임 | **실행 옵션 복구**를 누르고 게임을 다시 실행합니다. |
| `?`나 □가 나옴 | **한국어 환경으로 실행**을 켜고 게임을 다시 실행합니다. |
| 조합 창이 따로 뜸 | **조합 중 글자 바로 입력**을 고릅니다. |
| IME로는 전혀 안 들어감 | **붙여넣기로 입력**을 고릅니다. |
| 입력창을 다시 열면 한글이 안 들어감 | **Enter 후 IME 깨우기**를 켜고, 그래도 안 되면 **Enter 후 입력 대기**를 늘립니다. |
| 바로 입력에서 글자가 꼬이거나 쌓임 | **백스페이스 누름 시간**을 늘리거나 **지연 시간 줄이기**를 바꿔 봅니다. |
| 붙여넣기에서 글자가 빠짐 | **붙여넣기 간격**을 늘립니다. FPS가 낮은 게임일수록 길게 잡으세요. |
| 한/영 키가 게임 조작과 겹침 | **고급 → 한/영 전환 키**에서 해당 키를 끕니다. |

## 알려진 제한

- 게임이나 Proton 버전에 따라 동작이 다릅니다. FPS가 낮으면 입력이 불안정할 수 있습니다.
- 붙여넣기 방식은 입력한 글자가 클립보드에 남습니다.
- Steam 가상 키보드가 닫힌 채 **모아서 입력**의 입력줄이 떠 있는 동안에는 MangoHud 성능 표시가 잠시 사라집니다.
- Steam 업데이트로 Steam 가상 키보드 관련 기능이 동작하지 않을 수 있습니다. 이때는 원래 Steam 가상 키보드 방식으로 동작합니다.
- 안티치트가 있는 게임에서는 키 입력을 자동으로 보내는 기능(붙여넣기, IME 깨우기)의 사용에 주의하세요.

## 작동 방식과 개인정보

게임 화면마다 작은 입력 서버(XIM)를 실행하고, 실행 옵션의 `XMODIFIERS`로 게임이 이 서버를 쓰게 합니다. 게임 파일이나 DLL은 수정하지 않습니다.

입력한 글자를 기록하거나 외부로 보내지 않습니다. **모아서 입력**으로 Steam 가상 키보드 입력줄을 쓰는 동안에는 전송 전 글자가 사용자만 읽을 수 있는 임시 메모리 파일에 잠시 머물고, 보내거나 버리면 바로 지워집니다. Steam ID는 계정별 설정을 구분하기 위해 이 기기의 설정 파일에만 저장합니다.
