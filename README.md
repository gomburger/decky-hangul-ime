# Hangul IME Bridge

Steam Deck 게임 모드에서 Proton(Wine) 게임에 한글을 입력하게 해 주는 Decky Loader 플러그인입니다. Steam 키보드와 물리 키보드를 모두 지원합니다.

## 필요한 것

- 게임 모드로 실행 중인 Steam Deck
- [Decky Loader](https://decky.xyz/)
- Proton으로 실행하는 게임 (Steam 게임, 비 Steam 게임 모두 가능)

## 설치

1. [릴리스 페이지](https://github.com/gomburger/decky-hangul-ime/releases/latest)에서 `decky-hangul-ime-1.0.0.zip`을 Steam Deck에 내려받습니다.
2. Decky 설정에서 개발자 모드를 켭니다.
3. Decky 설정의 **개발자** 메뉴에서 **ZIP으로 플러그인 설치**를 선택하고 내려받은 파일을 고릅니다.

업데이트할 때도 새 ZIP을 같은 방법으로 설치하면 됩니다. 설정은 유지됩니다.

## 빠른 시작

1. 게임을 실행하고 Quick Access 메뉴(`…` 버튼)에서 **Decky → 한글 IME**를 엽니다.
2. **이 게임에서 사용**을 켭니다. 게임 실행 옵션에 `XMODIFIERS=@im=hangulbridge`가 자동으로 추가됩니다.
3. **게임을 완전히 끄고 다시 실행합니다.**
4. 입력창에서 한/영을 바꾸고 한글을 입력합니다.

한글이 `?`나 □로 보이거나 입력되지 않으면 **고급 → 실행 옵션**에서 `HOST_LC_ALL=ko_KR.UTF-8`을 복사해 게임 속성의 실행 옵션에 넣고 게임을 다시 실행해 보세요.

## 한/영 전환

| 방법 | 설명 |
|---|---|
| 물리 키보드 | 한/영 키, 오른쪽 Alt, Shift+Space. 고급 메뉴에서 쓸 키만 고를 수 있습니다. |
| 가/A 버튼 | 플러그인 화면의 버튼으로 전환합니다. 지금 상태를 보여 줍니다. |
| Steam 키보드 지구본 | 게임에 입력할 때 지구본 키가 한/영 전환 키가 됩니다. |

Steam 키보드 설정에 **한국어와 영어 자판을 함께 추가**해 두면 지구본으로 두 자판을 오갑니다.

## Steam 키보드

플러그인을 켠 게임에 입력할 때 Steam 키보드는 다음처럼 동작합니다.

- 한국어 자판이 그대로 보이고, 누른 자리의 글자를 플러그인이 두벌식으로 조합합니다.
- 한글 상태에서는 Caps Lock이 동작하지 않고, 길게 눌러도 확장 문자가 나오지 않습니다.

오버레이의 채팅이나 브라우저 같은 Steam 자체 입력창에서는 Steam 키보드가 원래대로 동작합니다.

## 게임별 옵션

**이 게임에서 사용**을 켠 게임에서만 보입니다.

### 키보드 닫으면 영문으로

게임에 입력하던 Steam 키보드를 닫으면 영문 상태로 바꾸고, 다시 열면 이전 한/영 상태로 돌아갑니다. 키보드로 조작하는 게임에서 조작키가 한글로 바뀌지 않게 합니다. 기본으로 켜져 있습니다.

### 글자 보내는 방식

아무것도 켜지 않으면 기본 방식(IME)으로 조합 중인 글자를 게임의 입력창에 보여 줍니다. 게임에 맞지 않을 때만 아래 방식 중 하나를 켜세요. 둘은 동시에 켤 수 없습니다.

| 방식 | 언제 쓰나요 | 알아둘 점 |
|---|---|---|
| **조합 중 글자 바로 입력** | 조합 창이 따로 뜨거나 조합 중인 글자가 안 보이는 게임 | 조합 중인 글자를 실제 글자로 입력하고, 바뀔 때마다 지웠다가 다시 입력합니다. |
| **붙여넣기로 입력** | IME로 한글이 들어가지 않지만 Ctrl+V는 되는 게임 | 입력할 때마다 클립보드 내용이 바뀌고, 조합 중인 글자는 보이지 않습니다. |

바로 입력의 세부 설정:

- **백스페이스 누름 시간** (기본 50ms): 글자가 꼬이거나 지워지지 않으면 늘립니다.
- **지연 시간 줄이기**: 백스페이스를 키 대신 문자로 보냅니다. 글자가 쌓이거나 □가 보이면 끕니다.

붙여넣기의 세부 설정:

- **붙여넣기 간격** (기본 35ms, 20~70ms): 글자가 빠지면 늘립니다. 기본값은 30fps까지를 기준으로 맞췄습니다.

### Enter 후 IME 깨우기

입력창을 닫았다가 다시 열면 한글이 들어가지 않고, 다른 키를 한 번 눌러야 들어가는 게임에서 켭니다. 기본 방식과 바로 입력에서 쓸 수 있고, 기본으로 꺼져 있습니다.

한글 상태에서 Enter를 누른 다음 첫 자모를 입력할 때, 그 앞에 F24 키를 한 번 눌러 게임이 IME를 켜게 합니다. 기다리는 동안 입력한 글자는 모아 두었다가 순서대로 보냅니다.

- **Enter 후 입력 대기** (기본 500ms, 0~1000ms, 50ms 단위): 글자가 빠지면 늘립니다. 값이 클수록 첫 글자가 늦게 나타납니다.

## 공통 설정

**편의 기능**

- **엔터 눌러도 키보드 유지**: Enter를 눌러도 Steam 키보드를 닫지 않습니다.
- **키보드 불투명도**: Steam 키보드를 반투명하게 합니다.

**고급**

- **상태**: 입력 서버 상태를 보여 줍니다. **일시 중지**를 켜면 입력 서버와 포커스 감지를 끕니다. 다시 켠 뒤에는 게임을 재시작하세요.
- **한/영 전환 키**: 한/영 키, 오른쪽 Alt, Shift+Space를 각각 켜고 끕니다. 꺼 둔 키는 게임에 그대로 들어갑니다.
- **실행 옵션**: 한국어 실행 옵션을 복사합니다.
- **현재 프로세스**: 실행 중인 게임 프로세스와 실행 옵션 적용 여부를 보여 줍니다.

**등록된 게임**에서 플러그인을 켠 게임을 확인하고 제거할 수 있습니다. 제거하면 실행 옵션의 `XMODIFIERS` 항목도 함께 지웁니다.

## 작동 원리

- 게임 화면마다 작은 입력 서버(XIM)를 실행합니다. 실행 옵션의 `XMODIFIERS=@im=hangulbridge`는 게임이 이 서버를 사용하게 합니다.
- 한글 상태에서는 게임으로 가는 키를 입력 서버가 먼저 받아 두벌식으로 조합하고, 선택한 방식으로 게임에 전달합니다.
- 영문 상태에서는 키가 입력 서버를 거치지 않고 게임으로 바로 갑니다.
- 플러그인은 게임 파일이나 DLL을 수정하지 않습니다.

## 문제 해결

| 증상 | 해 볼 것 |
|---|---|
| 토글을 켰는데 한글이 안 됨 | 게임을 완전히 끄고 다시 실행합니다. **고급 → 현재 프로세스**에서 "적용됨"인지 확인합니다. |
| `?`나 □가 나옴 | 실행 옵션에 `HOST_LC_ALL=ko_KR.UTF-8`을 추가합니다. |
| 조합 창이 따로 뜸 | **조합 중 글자 바로 입력**을 켭니다. |
| IME로는 전혀 안 들어감 | **붙여넣기로 입력**을 켭니다. |
| 입력창을 다시 열면 안 들어감 | **Enter 후 IME 깨우기**를 켭니다. |
| 붙여넣기에서 글자가 빠짐 | **붙여넣기 간격**을 늘립니다. |
| 한/영 키가 게임 조작과 겹침 | **고급 → 한/영 전환 키**에서 해당 키를 끕니다. |

## 알려진 제한

- 게임이나 Proton 버전에 따라 동작이 다릅니다.
- 붙여넣기 방식은 입력한 글자가 클립보드에 남습니다.
- 프레임이 낮을 때 Steam 키보드 입력이 불안정할 수 있습니다.
- Steam 업데이트로 Steam 키보드 관련 기능이 동작하지 않을 수 있습니다. 이때 Steam 키보드는 원래 방식으로 동작합니다.
- 안티치트가 있는 게임에서는 키 입력을 자동으로 보내는 기능(붙여넣기, IME 깨우기)의 사용에 주의하세요.

## 개인정보

입력한 글자를 기록하거나 외부로 보내지 않습니다. 플러그인 로그에는 등록한 게임의 앱 ID 같은 동작 정보만 남습니다.
